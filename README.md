## 📌 Sobre

Projeto final do curso de **React da DevMedia**. A aplicação simula o cardápio digital de um restaurante: o usuário navega pelos pratos por categoria, faz buscas e vê cada item com imagem, descrição e preço.

<br>

## ✨ Funcionalidades

| | Funcionalidade | Descrição |
|:---:|---|---|
| 🗂️ | **Categorias** | Entradas, Massas, Carnes, Bebidas, Saladas e Sobremesas |
| 🔎 | **Busca** | Encontre pratos pelo nome |
| 🃏 | **Cards de produto** | Imagem, nome, categoria, descrição e preço |
| 📱 | **Responsivo** | Layout adaptado para desktop e mobile |
| ⚡ | **Imagens otimizadas** | Carregamento rápido com `next/image` |

<br>

## 🚀 Como rodar localmente

> **Pré-requisito:** [Node.js](https://nodejs.org) 18+

```bash
git clone https://github.com/ErissonCavalcanti/cardapio-restaurante.git
cd cardapio-restaurante
npm install
npm run dev
```

Depois, acesse **http://localhost:3000**.

<br>

## 📁 Estrutura

```
cardapio-restaurante/
├── public/           → arquivos estáticos
├── src/              → componentes, páginas, estilos e dados
├── next.config.mjs
└── package.json
```
