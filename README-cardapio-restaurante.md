# 🍽️ Cardápio de Restaurante

Cardápio digital para restaurante, desenvolvido com **React** e **Next.js**. O usuário navega pelos pratos por categoria, faz buscas e vê cada item com imagem, descrição e preço.

🔗 **Acesse o projeto:** [cardapio-restaurante-murex.vercel.app](https://cardapio-restaurante-murex.vercel.app)

## ✨ Funcionalidades

- **Navegação por categorias:** Entradas, Massas, Carnes, Bebidas, Saladas e Sobremesas
- **Busca de pratos** pelo nome
- **Cards de produto** com imagem, nome, categoria, descrição e preço
- **Layout responsivo**, adaptado para desktop e mobile
- **Imagens otimizadas** com o componente `next/image`

## 🛠️ Tecnologias

| Tecnologia | Uso |
|---|---|
| [React](https://react.dev) | Componentização e gerenciamento de estado da interface |
| [Next.js](https://nextjs.org) | Framework, roteamento e otimização de imagens e fontes |
| JavaScript (ES6+) | Lógica de filtro e busca |
| CSS3 | Estilização e responsividade |
| [Vercel](https://vercel.com) | Deploy e hospedagem |

## 🚀 Como rodar localmente

**Pré-requisito:** [Node.js](https://nodejs.org) 18 ou superior

```bash
# Clone o repositório
git clone https://github.com/ErissonCavalcanti/cardapio-restaurante.git

# Entre na pasta
cd cardapio-restaurante

# Instale as dependências
npm install

# Rode o servidor de desenvolvimento
npm run dev
```

Depois, abra [http://localhost:3000](http://localhost:3000) no navegador.
